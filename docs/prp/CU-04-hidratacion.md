# PRP CU-04 — Registro rápido de hidratación
## Flujo principal
1. El usuario toca "Vaso 250 ml" / "Botella 500 ml" / cantidad libre. 2. Se guarda en `water_entries`. 3. El vaso visual sube.
## Alternativos
- "Deshacer" elimina el último registro de hoy.
## Criterios de aceptación
- [ ] Dados 250+500 ml hoy y meta 2000, el progreso es 37.5 %.
